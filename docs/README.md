# Documentation

Start with the [project README](../README.md) to run the playground and try its main interactions. These pages provide the next layer of detail:

- [Features](features.md): what works in the browser, including permanent app shortcuts, canvas drawings, spatial search, and same-app gathering, what is simulated, and which choices are remembered.
- [Visual language](visual-language.md): the reasoning behind the four corners, restrained shell text, user-drawn content, temporary search and switching arrangements, glass and opaque layers, shared colors, and varied app identities.
- [Spatial playground](spatial-playground.md): canvas coordinates, drawing layers, window and tool behavior, search and switching layouts and transitions, component ownership, and persistence details.
- [Drawing recognition](recognition.md): local gesture matching, rejection behavior, and the reference implementation's license.

For development commands and verification, see [CONTRIBUTING.md](../CONTRIBUTING.md). [Temporary notes](../notes/README.md) contain provisional, untrusted material rather than maintained guidance.
