# Documentation

Start with the [project README](../README.md) to run the playground and try its main interactions. These pages provide the next layer of detail:

- [Features](features.md): what works in the browser, including configurable frame groups, status detail, drag-to-favorite shortcuts, pinned-window reveal, removable controls, Alt alignment with dots, selecting and moving canvas controls with desktop icons, peeking, drawings, unified search with live control previews and tool actions, and same-app gathering; also what is simulated and saved.
- [A canvas inside a frame](canvas-and-frame.md): the spatial model for configurable edge attachments and groups, dragging between frame and canvas, background and raised objects beneath windows, Change layout, independent status controls, favorites, removable controls, and search recovery.
- [Visual language](visual-language.md): the reasoning behind the default corners, consistent frame spacing, user-controlled attachments, restrained shell text, visible clues to covered work, temporary search and switching arrangements, glass and opaque layers, shared colors, and varied app identities.
- [Spatial playground](spatial-playground.md): one scene with exclusive object locations, overlap grouping, full window and drawing presentations, direct frame editing, toolbar orientation at corners, favorites and status detail, canvas coordinates and snapping, mixed icon/control selection, object layers, window exposure, search actions and transitions, shared control state, component ownership, persistence, and the deliberate reset of older saved layouts.
- [Drawing recognition](recognition.md): local gesture matching and handwritten search, model downloads, worker ownership, rejection behavior, and the gesture reference implementation's license.

For development commands and verification, see [CONTRIBUTING.md](../CONTRIBUTING.md). [Temporary notes](../notes/README.md) contain provisional, untrusted material rather than maintained guidance.
