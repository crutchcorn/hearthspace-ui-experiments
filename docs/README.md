# Documentation

Start with the [project README](../README.md) to run the playground and try its main interactions. These pages provide the next layer of detail:

- [Features](features.md): what works in the browser, including peeking after window moves and launches, temporary background-object movement, canvas drawings, typed and handwritten spatial search, and same-app gathering, what is simulated, and which choices are remembered.
- [Visual language](visual-language.md): the reasoning behind the four corners, restrained shell text, visible clues to covered work, background objects returning home, user-drawn content, temporary search and switching arrangements, glass and opaque layers, shared colors, and varied app identities.
- [Spatial playground](spatial-playground.md): canvas coordinates, drawing layers, window exposure, how background items return together, tool behavior, search and switching transitions, component ownership, persistence, and migration of older saved layouts.
- [Drawing recognition](recognition.md): local gesture matching and handwritten search, model downloads, worker ownership, rejection behavior, and the gesture reference implementation's license.

For development commands and verification, see [CONTRIBUTING.md](../CONTRIBUTING.md). [Temporary notes](../notes/README.md) contain provisional, untrusted material rather than maintained guidance.
