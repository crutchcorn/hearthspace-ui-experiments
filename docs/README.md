# Documentation

Start with the [project README](../README.md) to run the playground and try its main interactions. These pages provide the next layer of detail:

- [Features](features.md): what works in the browser, including configurable frame attachments, pinned-window reveal, removable controls and recovery, Alt alignment with dots, peeking, drawings, unified search, and same-app gathering; also what is simulated and saved.
- [A canvas inside a frame](canvas-and-frame.md): the spatial model for configurable edge attachments, canvas layers, Change layout, removable controls, and search recovery.
- [Visual language](visual-language.md): the reasoning behind the default corners, consistent frame spacing, user-controlled attachments, restrained shell text, visible clues to covered work, temporary search and switching arrangements, glass and opaque layers, shared colors, and varied app identities.
- [Spatial playground](spatial-playground.md): placement ownership, direct frame editing, canvas coordinates and snapping, object layers, window exposure, search recovery and transitions, component ownership, persistence, and migration of older saved layouts.
- [Drawing recognition](recognition.md): local gesture matching and handwritten search, model downloads, worker ownership, rejection behavior, and the gesture reference implementation's license.

For development commands and verification, see [CONTRIBUTING.md](../CONTRIBUTING.md). [Temporary notes](../notes/README.md) contain provisional, untrusted material rather than maintained guidance.
